A minimal, elegant, editorial-style portfolio and blog theme for WordPress developers, technical support engineers, designers, freelancers, consultants, and technical writers.

== Description ==

Pixelpost is crafted with an editorial eye: warm ivory backgrounds, deep charcoal serif headings, restrained terracotta accents, and soft cream surface panels.

Features:
* Classic PHP WordPress theme architecture with full Gutenberg support.
* Complete WordPress Customizer integration for colors, typography, header, and all homepage sections.
* Compact horizontal statistics strip.
* Skill pills collection.
* Work experience vertical timeline.
* Editorial responsive project and blog card grids.
* Contact & Collaboration section with mailto CTA, scheduling link, and a 3-row surface info card.
* Fully responsive across desktop (1440px), tablet (768px), and mobile (390px/320px).
* Zero third-party page builders or heavy dependencies required.

== Installation ==

1. In your WordPress admin, go to Appearance > Themes and click "Add New".
2. Click "Upload Theme" and select `pixelpost.zip`.
3. Click "Install Now" and then "Activate".
4. Navigate to Appearance > Customize to adjust your branding, colors, hero text, and portfolio sections.
